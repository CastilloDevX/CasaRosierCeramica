# Footer editable

Enfoque: CMS
Tipo: Feature

En el footer editable:
![Ejemplo](image-1.png)
- Se podrá modificar los colores de los botones como: "Enviar" del formulario y los botones de las redes sociales.
- Se podrá modificar los links de las redes sociales.
- Se podrá modificar el texto de: "Contacto" y su descripción que dice:
"""
+34 600 000 000
Barcelona, España
Lunes a Sabado - 10:00 a 20:00
Siguenos en Nuestras Redes:
"""
Permitiendo saltos de linea.
- Los botones de "Administración" y "Política y privacidad" se quedan ahí, no se modificarán.
- Se podrá añadir más redes sociales, permitiendo agregar el link de la red social y el icono con un texto que diga "Es recomendable que el icono sea completamente blanco para que se pueda editar fácilmente".
- Por cada icono de red social como facebook o instagram se podrá editar su color de imagen.
- Eliminar del footer la clase "hover" para cambiar de color, ya que como se puede editar los colores, es mejor simplemente dejar un solo color, en este caso el color editable.

Crear las tablas respectivas para la base de datos en supabase para que se puedan aplicar los cambios al footer.

El footer se ve en todas las páginas asi que si o si las modificaciones deben reflejarse.
